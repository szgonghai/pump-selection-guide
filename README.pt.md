## 🧪 Decisão de Seleção (4 Passos)

### Passo 1 · Tipo de Meio (Determina Tipo de Bomba)
```
                ┌─ Sólidos / Alta viscosidade / Abrasivo ──→ Diafragma (ARO)
                │
Meio ─┤ Ácido forte / Base / Inflamável ──→ Magnética (PTCXPUMP/INNOMAG)
                │
                ├─ Dosagem precisa / Quantitativa ──→ Dosificadora
                │
                └─ Água limpa / Baixa viscosidade / Circulação ──→ Centrífuga (PTCXPUMP)
```

### Passo 2 · Parâmetros Chave
| Parâmetro | Consideração |
|-----------|---------------|
| **Vazão** | Demanda do processo (normal + pico) |
| **Altura manométrica** | Resistência do sistema + altura estática + margem de segurança |
| **Temperatura** | Afeta escolha do material (PTFE / ETFE / SS) |
| **Pressão** | Pressão de trabalho vs pressão nominal da bomba |
| **Viscosidade** | Alta viscosidade requer mais potência |
| **Teor de sólidos** | Com partículas → diafragma ou parafuso requerido |

### Passo 3 · Requisitos Especiais
| Requisito | Seleção |
|-----------|---------|
| **Zero vazamentos** (perigoso/corrosivo) | Bomba Magnética |
| **Marcha a seco** (anti-cavitação) | Bomba de Diafragma |
| **Alta pureza** (semicondutor/alimentação) | Bomba Magnética (316L polido) |
| **Alta pressão** (> 10 bar) | Magnética / Centrífuga |
| **À prova de explosão** (gás inflamável) | Magnética (sem motor) / ARO (pneumática) |
| **Resistente a ácidos fortes** | Magnética (PTCXPUMP plástico técnico / INNOMAG ETFE) |

## ❓ Perguntas Frequentes

<details>
<summary><b>P1: Bomba magnética ou centrífuga?</b></summary>

**Magnética**: Selo estático, zero vazamentos, adequado para ácidos fortes/bases/inflamáveis/alta pureza. **Centrífuga**: Alta eficiência, versátil, grande vazão, mas risco de vazamento do selo mecânico, não para alta viscosidade. Indústria padrão → centrífuga; meios perigosos/corrosivos → magnética.
</details>

<details>
<summary><b>P2: Diafragma pneumático ou elétrico?</b></summary>

Pneumático (ARO) usa ar comprimido, **marcha a seco, à prova de explosão**, adequado para meios perigosos. Elétrico usa motor, sem fonte de ar mas risco de faísca. A Gonghai distribui **bombas de diafragma pneumáticas ARO** para química/farmacêutica/alimentação/eletrônica.
</details>

<details>
<summary><b>P3: Engrenagem interna ou bomba centrífuga?</b></summary>

Engrenagem interna é bomba de deslocamento positivo, para **fluidos de alta viscosidade** (1~500.000 mPa·s), vazão pequena, pressão alta. Centrífuga é bomba de velocidade, para **grande vazão baixa viscosidade**. A DAIDO distribui bombas de engrenagem para química/resina/óleo aplicações de alta viscosidade.
</details>
