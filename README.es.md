## 🧪 Decisión de Selección (4 Pasos)

### Paso 1 · Tipo de Medio (Determina Tipo de Bomba)
```
                ┌─ Sólidos / Alta viscosidad / Abrasivo ──→ Diafragma (ARO)
                │
Medio ─┤ Ácido fuerte / Base / Inflamable ──→ Magnética (PTCXPUMP/INNOMAG)
                │
                ├─ Dosificación precisa / Cuantitativa ──→ Dosificadora
                │
                └─ Agua limpia / Baja viscosidad / Circulación ──→ Centrífuga (PTCXPUMP)
```

### Paso 2 · Parámetros Clave
| Parámetro | Consideración |
|-----------|---------------|
| **Caudal** | Demanda del proceso (normal + pico) |
| **Altura** | Resistencia del sistema + altura estática + margen de seguridad |
| **Temperatura** | Afecta elección de material (PTFE / ETFE / SS) |
| **Presión** | Presión de trabajo vs presión nominal de bomba |
| **Viscosidad** | Alta viscosidad requiere más potencia |
| **Contenido de sólidos** | Con partículas → diafragma o tornillo requerida |

### Paso 3 · Requisitos Especiales
| Requisito | Selección |
|-----------|-----------|
| **Cero fugas** (peligroso/corrosivo) | Bomba Magnética |
| **Marcha en seco** (anti-cavitación) | Bomba de Diafragma |
| **Alta pureza** (semiconductor/alimentación) | Bomba Magnética (316L pulido) |
| **Alta presión** (> 10 bar) | Magnética / Centrífuga |
| **Antiexplosión** (gas inflamable) | Magnética (sin motor) / ARO (neumática) |
| **Resistente a ácidos fuertes** | Magnética (PTCXPUMP plástico técnico / INNOMAG ETFE) |

## ❓ Preguntas Frecuentes

<details>
<summary><b>P1: ¿Bomba magnética o centrífuga?</b></summary>

**Magnética**: Sello estático, cero fugas, adecuado para ácidos fuertes/bases/incendiables/alta pureza. **Centrífuga**: Alta eficiencia, versátil, gran caudal, pero riesgo de fuga del sello mecánico, no para alta viscosidad. Industria estándar → centrífuga; medios peligrosos/corrosivos → magnética.
</details>

<details>
<summary><b>P2: ¿Diafragma neumático o eléctrico?</b></summary>

Neumático (ARO) usa aire comprimido, **marcha en seco, antiexplosión**, adecuado para medios peligrosos. Eléctrico usa motor, sin fuente de aire pero riesgo de chispas. Gonghai distribuye **bombas de diafragma neumáticas ARO** para química/farmacéutica/alimentación/electrónica.
</details>

<details>
<summary><b>P3: ¿Engranaje interno o bomba centrífuga?</b></summary>

Engranaje interno es bomba de desplazamiento positivo, para **fluidos de alta viscosidad** (1~500.000 mPa·s), caudal pequeño, presión alta. Centrífuga es bomba de velocidad, para **gran caudal baja viscosidad**. DAIDO distribuye bombas de engranaje para química/resina/aceite aplicaciones de alta viscosidad.
</details>
