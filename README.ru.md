## 🧪 Принятие решения (4 шага)

### Шаг 1 · Тип среды (определяет тип насоса)
```
                ┌─ Твёрдые / Высокая вязкость / Абразивные ──→ Мембранный (ARO)
                │
Среда ─┤ Сильная кислота / щёлочь / горючие ──→ Магнитный (PTCXPUMP/INNOMAG)
                │
                ├─ Точная дозировка / Количественная ──→ Дозирующий
                │
                └─ Чистая вода / Низкая вязкость / Циркуляция ──→ Центробежный (PTCXPUMP)
```

### Шаг 2 · Ключевые параметры
| Параметр | Учёт |
|-----------|------------|
| **Расход** | Требование процесса (нормальный + пиковый) |
| **Напор** | Сопротивление системы + статический напор + запас |
| **Температура** | Влияет на выбор материала (PTFE / ETFE / SS) |
| **Давление** | Рабочее давление vs номинальное давление насоса |
| **Вязкость** | Высокая вязкость требует большей мощности |
| **Содержание твёрдых частиц** | С частицами → мембранный или шнековый |

### Шаг 3 · Особые требования
| Требование | Подбор |
|-------------|---------|
| **Нулевая утечка** (опасные/коррозионные среды) | Магнитный насос |
| **Сухой ход** (защита от кавитации) | Мембранный насос |
| **Высокая чистота** (полупроводники/пищевая) | Магнитный насос (316L полированный) |
| **Высокое давление** (> 10 бар) | Магнитный / Центробежный |
| **Взрывозащита** (горючие газы) | Магнитный (без мотора) / ARO (пневматический) |
| **Устойчивость к сильным кислотам** | Магнитный (PTCXPUMP конструкционный пластик / INNOMAG ETFE) |

## ❓ Часто задаваемые вопросы

<details>
<summary><b>В1: Магнитный или центробежный насос?</b></summary>

**Магнитный**: Статическое уплотнение, нулевая утечка, подходит для сильных кислот/щелочей/горючих/высокой чистоты. **Центробежный**: Высокий КПД, универсальность, большой расход, но риск утечки механического уплотнения, не для высокой вязкости. Обычная промышленность → центробежный; опасные/коррозионные среды → магнитный.
</details>

<details>
<summary><b>В2: Пневматический или электрический мембранный насос?</b></summary>

Пневматический (ARO) использует сжатый воздух, **сухой ход, взрывозащита**, подходит для опасных сред. Электрический использует мотор, не требует воздушного источника, но есть риск искрения. Gonghai распространяет **пневматические мембранные насосы ARO** для химии/фармацевтики/пищевой/электроники.
</details>

<details>
<summary><b>В3: Шестерёнчатый с внутренним зацеплением или центробежный?</b></summary>

Шестерёнчатый с внутренним зацеплением — объёмный насос, для **высоковязких сред** (1~500.000 мПа·с), малый расход, высокое давление. Центробежный — скоростной насос, для **большого расхода низкой вязкости**. DAIDO распространяет шестерёнчатые насосы для химии/смол/масел — высоковязкие применения.
</details>
