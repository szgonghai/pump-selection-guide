## 泵浦类型

### 1. 磁力泵
- **适用介质**：强酸 / 强碱 / 易燃 / 高纯
- **核心优势**：静密封 · 零泄漏 · 适合危险介质
- **限制**：不适合含固体颗粒 / 效率低于离心泵
- **代理主推**：
  - PTCXPUMP PS / PL 系列（316L 不锈钢）
  - INNOMAG U-MAG / TB-MAG 系列（ETFE 衬里）

### 2. 气动隔膜泵
- **适用介质**：含固体 / 高粘度 / 磨蚀 / 浆料
- **核心优势**：可干转 / 强通过性 / 防爆 / 适合危险品
- **限制**：脉动流 / 效率较低
- **代理主推**：ARO Pro / EXP 系列（气动）

### 3. 计量泵
- **适用介质**：精确加药 / 定量投加
- **核心优势**：精准计量 / 可调冲程
- **代理主推**：顺益（SHUN-YI）系列，精度 ±0.5%

### 4. 离心泵
- **适用介质**：清水 / 低粘度 / 循环
- **核心优势**：高效 / 通用 / 结构简单
- **限制**：机封泄漏风险 / 不适合高粘度
- **代理主推**：PTCXPUMP Standard（5-500 m³/h）

### 5. 内转齿轮泵 / 转子泵
- **适用介质**：高粘度（1~500,000 mPa·s）/ 含微量颗粒
- **核心优势**：容积式 / 强自吸
- **代理主推**：DAIDO G / SE / TG / MAG / NR 系列

## 选型决策树

```
            ┌─ 含颗粒/高粘/磨蚀 ──→ 气动隔膜泵 (ARO)
            │
介质 ─┤ 强酸/强碱/易燃 ──→ 磁力泵 (PTCXPUMP / INNOMAG)
            │
            ├─ 精确加药/定量 ──→ 计量泵 (顺益)
            │
            ├─ 清水/低粘/循环 ──→ 离心泵 (PTCXPUMP)
            │
            └─ 高粘度/容积式 ──→ 内转齿轮泵 (DAIDO)
```

## 行业应用

- **半导体 / 电子级**：PTCXPUMP PL/PM/PS（无泄漏 + 316L）
- **化工 / 电镀**：PTCXPUMP PTC（工程塑料耐酸碱）
- **制药 / 食品**：PTCXPUMP PS（316L 抛光 + GMP）
- **环保 / 废水**：ARO 隔膜泵（含固 + 可干转）
- **加药系统**：顺益（SHUN-YI）计量泵（±0.5%）
- **石油 / 化工 / 加氢站**：PTCXPUMP PS（耐高压高温）
- **离岸风电 / 氢能**：PTCXPUMP PL/PM/PS（金属不锈钢）
- **树脂 / 油脂 / 高粘度**：DAIDO 内转齿轮泵

## 选型参数清单

- 介质（成分 / 浓度 / 黏度 / 温度 / 密度）
- 流量（正常 + 峰值）

- 压力（工作压力 + 最大压力）
- 固体含量
- 环境要求（防爆 / GMP / 室外 / 海边）
