## 🧪 選型決策（4 步走）

### Step 1 · 介質類型（決定泵型）
```
                ┌─ 含顆粒/高黏度/磨蝕 ──→ 隔膜泵 (ARO)
                │
介質 ─┤ 強酸/強鹼/易燃 ──→ 磁力泵 (PTCXPUMP/INNOMAG)
                │
                ├─ 精準加藥/定量 ──→ 計量泵
                │
                └─ 清水/低黏度/循環 ──→ 離心泵 (PTCXPUMP)
```

### Step 2 · 關鍵參數
| 參數 | 關注點 |
|------|------|
| **流量** | 工藝需求流量（含峰值）|
| **揚程** | 系統阻力 + 靜揚程 + 安全餘量 |
| **溫度** | 影響材質選擇（PTFE / ETFE / 不鏽鋼）|
| **壓力** | 工作壓力 vs 泵的額定壓力 |
| **黏度** | 高黏度需要更大功率 |
| **固體含量** | 含固 → 必須選隔膜泵或螺旋泵 |

### Step 3 · 特殊要求
| 要求 | 選型 |
|------|------|
| **零洩漏**（危險/腐蝕介質）| 磁力泵 |
| **可乾轉**（防氣蝕）| 隔膜泵 |
| **高潔淨**（半導體/食品）| 磁力泵（316L 拋光）|
| **高壓**（> 10 bar）| 磁力泵 / 離心泵 |
| **防爆**（易燃氣體）| 磁力泵（無馬達）/ ARO（氣動）|
| **耐強酸** | 磁力泵（PTCXPUMP 工程塑料 / INNOMAG ETFE）|

## ❓ 常見問題

<details>
<summary><b>Q1：磁力泵和離心泵怎麼選？</b></summary>

**磁力泵**：靜密封，零洩漏，適合強酸/強鹼/易燃/高純介質；**離心泵**：高效、通用、大流量，但有機封洩漏風險，不適合高黏度。普通工業選離心泵，危險/腐蝕介質選磁力泵。
</details>

<details>
<summary><b>Q2：氣動隔膜泵和電動泵的區別？</b></summary>

氣動（ARO）以壓縮空氣為動力，**可乾轉、防爆**，適合含顆粒/高黏度/危險品；電動以馬達驅動，無氣源但有電火風險。弓海主推 **ARO 氣動隔膜泵**，覆蓋化工/製藥/食品/電子等行業。
</details>

<details>
<summary><b>Q3：內轉齒輪泵和離心泵的區別？</b></summary>

內轉齒輪泵是容積式泵，適合**高黏度流體**（1~500,000 mPa·s），但流量小、壓力高；離心泵是速度式泵，適合**大流量低黏度**。DAIDO 代理的齒輪泵覆蓋化工/樹脂/油脂等高黏度應用。
</details>
