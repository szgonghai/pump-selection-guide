# Руководство по выбору промышленных насосов

> **Как выбрать правильный насос для вашего применения**  
> На основе 40-летнего опыта, охватывающего магнитные, центробежные, диафрагменные и дозирующие насосы.

## Дерево решений выбора

```
НАЧАЛО
  ↓
[В1] Является ли среда токсичной / горючей / сильно коррозионной?
  ↓ ДА                  ↓ НЕТ
Магнитный насос    [В2] Требуется точное дозирование?
                    ↓ ДА              ↓ НЕТ
              Дозирующий насос  [В3] Содержит твердые частицы или высокую вязкость?
                                ↓ ДА              ↓ НЕТ
                          Диафрагменный насос  Центробежный насос
```

## Таблица быстрого выбора

| Характеристики среды | Рекомендуемый насос | Основная причина |
|---------------------|---------------------|------------------|
| Сильно коррозионная, горючая | Магнитный насос | Статическое уплотнение, отсутствие утечки |
| Точное дозирование | Дозирующий насос | Высокая точность расхода |
| Твердые частицы, высокая вязкость | Диафрагменный насос | Хорошая проходимость |
| Низкая вязкость, чистая вода | Центробежный насос | Универсальность, высокий КПД |

## Ключевые параметры выбора

- **Свойства среды**: концентрация, температура, плотность, вязкость
- **Требования к расходу**: максимальный расход, нормальный расход
- **Требования к напору**: фактический напор, потери на трение
- **Выбор материала**: металл (нержавейка/сплав) или неметалл (PP/PVDF/ETFE)
- **Температурный диапазон**: рабочая температура, максимальная температура
- **Требования к чистоте**: SEMI, фармацевтический класс
