## 🧪 Auswahlentscheidung (4 Schritte)

### Schritt 1 · Mediumtyp (Bestimmt Pumpentyp)
```
                ┌─ Feststoffe / Hohe Viskosität / Abrasiv ──→ Membranpumpe (ARO)
                │
Medium ─┤ Starke Säure / Base / Brennbar ──→ Magnetpumpe (PTCXPUMP/INNOMAG)
                │
                ├─ Präzise Dosierung / Quantitativ ──→ Dosierpumpe
                │
                └─ Sauberes Wasser / Niedrige Viskosität / Zirkulation ──→ Kreiselpumpe (PTCXPUMP)
```

### Schritt 2 · Schlüsselparameter
| Parameter | Überlegung |
|-----------|---------------|
| **Durchsatz** | Prozessbedarf (normal + Spitze) |
| **Förderhöhe** | Systemwiderstand + statische Höhe + Sicherheitsmarge |
| **Temperatur** | Beeinflusst Materialwahl (PTFE / ETFE / SS) |
| **Druck** | Betriebsdruck vs. Pumpennenndruck |
| **Viskosität** | Hohe Viskosität erfordert mehr Leistung |
| **Feststoffgehalt** | Partikel → Membran- oder Schneckenpumpe erforderlich |

### Schritt 3 · Besondere Anforderungen
| Anforderung | Auswahl |
|-------------|---------|
| **Null Leckage** (gefährlich/korrosiv) | Magnetpumpe |
| **Trockenlauffähig** (Kavitationsschutz) | Membranpumpe |
| **Hohe Reinheit** (Halbleiter/Lebensmittel) | Magnetpumpe (316L poliert) |
| **Hochdruck** (> 10 bar) | Magnetpumpe / Kreiselpumpe |
| **Explosionsgeschützt** (brennbare Gase) | Magnetpumpe (ohne Motor) / ARO (pneumatisch) |
| **Starke Säurebeständigkeit** | Magnetpumpe (PTCXPUMP Konstruktionskunststoff / INNOMAG ETFE) |

## ❓ FAQ

<details>
<summary><b>F1: Magnetpumpe oder Kreiselpumpe?</b></summary>

**Magnetpumpe**: Statische Dichtung, null Leckage, geeignet für starke Säure/Base/brennbar/hohe Reinheit. **Kreiselpumpe**: Hohe Effizienz, vielseitig, großer Durchsatz, aber mechanische Dichtungsleckage, nicht für hohe Viskosität. Standardindustrie → Kreiselpumpe; gefährlich/korrosiv → Magnetpumpe.
</details>

<details>
<summary><b>F2: Pneumatische oder elektrische Membranpumpe?</b></summary>

Pneumatisch (ARO) verwendet Druckluft, **trockenlauffähig, explosionsgeschützt**, für gefährliche Medien. Elektrisch verwendet Motor, keine Luftquelle nötig, aber Funkenrisiko. Gonghai vertreibt **ARO pneumatische Membranpumpen** für Chemie/Pharma/Lebensmittel/Elektronik.
</details>

<details>
<summary><b>F3: Innenzahnrad- oder Kreiselpumpe?</b></summary>

Innenzahnrad ist Verdrängerpumpe, für **hochviskose Medien** (1~500.000 mPa·s), kleiner Durchsatz, hoher Druck. Kreiselpumpe ist Strömungspumpe, für **großen Durchsatz, niedrige Viskosität**. DAIDO vertreibt Zahnradpumpen für Chemie/Harz/Öl hochviskose Anwendungen.
</details>
