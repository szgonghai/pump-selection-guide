## 🧪 選定決定（4 ステップ）

### Step 1 · 流体タイプ（ポンプタイプ決定）
```
                ┌─ 固体/高粘度/摩耗 ──→ ダイアフラム (ARO)
                │
流体 ─┤ 強酸/強塩基/可燃 ──→ マグネット (PTCXPUMP/INNOMAG)
                │
                ├─ 精密薬注/定量 ──→ 計量
                │
                └─ 清水/低粘度/循環 ──→ 遠心 (PTCXPUMP)
```

### Step 2 · 主要パラメータ
| パラメータ | 注意点 |
|-----------|---------------|
| **流量** | プロセス要求（通常+ピーク）|
| **揚程** | システム抵抗 + 静揚程 + 安全マージン |
| **温度** | 材質選択に影響（PTFE / ETFE / SS）|
| **圧力** | 使用圧力 vs ポンプ定格圧力 |
| **粘度** | 高粘度は大きな動力必要 |
| **固体含有** | 含有 → ダイアフラムまたはネジ式必須 |

### Step 3 · 特殊要件
| 要件 | 選定 |
|-------------|---------|
| **漏れゼロ**（危険/腐食流体）| マグネット |
| **ドライラン可**（キャビテーション防止）| ダイアフラム |
| **高純度**（半導体/食品）| マグネット（316L 研磨）|
| **高圧**（> 10 bar）| マグネット / 遠心 |
| **防爆**（可燃性ガス）| マグネット（モーターなし）/ ARO（空圧）|
| **強酸耐性** | マグネット（PTCXPUMP エンジニアリングプラスチック / INNOMAG ETFE）|

## ❓ よくある質問

<details>
<summary><b>Q1：マグネットポンプと遠心ポンプの選択は？</b></summary>

**マグネット**：静密封、漏れゼロ、強酸/強塩基/可燃/高純流体向け。**遠心**：高効率、汎用、大流量ですがメカニカルシール漏れリスク、高粘度不適。一般工業は遠心、危険/腐食流体はマグネット。
</details>

<details>
<summary><b>Q2：空圧ダイアフラムと電動ポンプの違いは？</b></summary>

空圧（ARO）は圧縮空気駆動、**ドライラン可、防爆**、危険品適。電動はモーター駆動、空気源不要だが火花リスク。弓海は **ARO 空圧ダイアフラムポンプ**を主推、化学/製薬/食品/電子などに対応。
</details>

<details>
<summary><b>Q3：内転ギアと遠心ポンプの違いは？</b></summary>

内転ギアは容積式ポンプ、**高粘度流体**（1~500,000 mPa·s）向け、流量小・圧力高。遠心は速度式ポンプ、**大流量低粘度**向け。DAIDO 代理のギアポンプは化学/樹脂/油脂など高粘度用途をカバー。
</details>
