# 按介质选型详细指南

## 强酸强碱

**推荐**：磁力泵（PTCXPUMP 工程塑料 / INNOMAG 内衬）

**原因**：
- 机械轴封会被强酸碱腐蚀
- 磁力泵是静密封，无轴封泄漏风险

**选型要点**：
- 浓硫酸（>70%）：建议 ETFE/PFA 内衬
- 盐酸：工程塑料（PP、PVDF）即可
- 硝酸：不锈钢（316L）或 ETFE
- 氢氧化钠：普通不锈钢即可

## 易燃易爆

**推荐**：磁力泵 + 配套防爆马达

**原因**：
- 机械轴封微量泄漏可能引起火灾爆炸
- 磁力泵彻底消除轴封泄漏源

**配套**：
- ATEX 防爆认证马达
- 防静电隔离罩
- 接地保护

## 高纯试剂

**推荐**：内衬磁力泵（INNOMAG TB-MAG）

**原因**：
- 介质只接触铁氟龙内衬
- 符合 SEMI 标准
- 零金属离子析出

## 清水循环

**推荐**：离心泵

**原因**：
- 成本最低
- 维护简单
- 大流量首选

**选型要点**：
- 一般工业循环水：标准离心泵
- 高温循环水：高温离心泵
- 大流量：双吸离心泵
