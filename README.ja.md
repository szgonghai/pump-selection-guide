# 工業ポンプ選定ガイド

> **あなたのアプリケーションに最適なポンプの選び方**  
> 40年の業界経験に基づき、マグネチックポンプ、遠心ポンプ、ダイアフラムポンプ、メータリングポンプをカバー。

## 選定決定ツリー

```
開始
  ↓
[Q1] 媒体は有毒/可燃性/強腐食性？
  ↓ YES                ↓ NO
マグネチックポンプ   [Q2] 精密定量添加が必要？
                    ↓ YES              ↓ NO
                メータリングポンプ  [Q3] 固体含有または高粘度？
                                    ↓ YES              ↓ NO
                                ダイアフラムポンプ  遠心ポンプ
```

## クイック選定表

| 媒体特性 | 推奨ポンプ | 主な理由 |
|---------|-----------|---------|
| 強腐食性、可燃性 | マグネチックポンプ | 静的シール、漏れなし |
| 精密定量 | メータリングポンプ | 高流量精度 |
| 固体含有、高粘度 | ダイアフラムポンプ | 良好な通過性 |
| 低粘度、清水 | 遠心ポンプ | 汎用性、高効率 |

## 重要な選定パラメータ

- **媒体特性**: 濃度、温度、密度、粘度
- **流量要件**: 最大流量、通常流量
- **揚程要件**: 実際揚程、摩擦損失
- **材料選択**: 金属（ステンレス/合金）または非金属（PP/PVDF/ETFE）
- **温度範囲**: 操作温度、最高温度
- **清浄度要件**: SEMI、製薬グレード
