## 🧪 قرار الاختيار (4 خطوات)

### الخطوة 1 · نوع الوسط (يحدد نوع المضخة)
```
                ┌─ مواد صلبة / لزوجة عالية / كاشطة ──→ غشائية (ARO)
                │
الوسط ─┤ حمض قوي / قلوي / قابل للاشتعال ──→ مغناطيسية (PTCXPUMP/INNOMAG)
                │
                ├─ جرعات دقيقة / كمّية ──→ جرعات
                │
                └─ ماء نظيف / لزوجة منخفضة / دورة ──→ طاردة مركزية (PTCXPUMP)
```

### الخطوة 2 · المعلمات الرئيسية
| المعلم | الاعتبار |
|--------|-----------|
| **التدفق** | طلب العملية (عادي + ذروة) |
| **الرأس** | مقاومة النظام + رأس ثابت + هامش أمان |
| **درجة الحرارة** | يؤثر على اختيار المادة (PTFE / ETFE / SS) |
| **الضغط** | ضغط العمل مقابل الضغط المقنن للمضخة |
| **اللزوجة** | لزوجة عالية تتطلب طاقة أكبر |
| **محتوى المواد الصلبة** | مع جسيمات → غشائية أو حلزونية مطلوبة |

### الخطوة 3 · متطلبات خاصة
| المتطلب | الاختيار |
|---------|---------|
| **صفر تسرب** (خطرة/مُسببة للتآكل) | مضخة مغناطيسية |
| **تشغيل جاف** (مضاد للتجويف) | مضخة غشائية |
| **نقاء عالٍ** (أشباه الموصلات/الأغذية) | مضخة مغناطيسية (316L مصقول) |
| **ضغط عالٍ** (> 10 بار) | مغناطيسية / طاردة مركزية |
| **مانع للانفجار** (غاز قابل للاشتعال) | مغناطيسية (بدون محرك) / ARO (هوائية) |
| **مقاومة الأحماض القوية** | مغناطيسية (PTCXPUMP بلاستيك هندسي / INNOMAG ETFE) |

## ❓ الأسئلة الشائعة

<details dir="rtl">
<summary><b>س1: المضخة المغناطيسية أم الطاردة المركزية؟</b></summary>

**المغناطيسية**: ختم ثابت، صفر تسرب، مناسبة للأحماض/القلويات القوية/القابلة للاشتعال/النقاء العالي. **الطاردة المركزية**: كفاءة عالية، متعددة الاستخدامات، تدفق كبير، لكن خطر تسرب الختم الميكانيكي، غير مناسبة للزوجة العالية. الصناعة العادية → طاردة مركزية; الوسائط الخطرة/المُسببة للتآكل → مغناطيسية.
</details>

<details dir="rtl">
<summary><b>س2: غشائية هوائية أم كهربائية؟</b></summary>

الهوائية (ARO) تستخدم الهواء المضغوط، **تشغيل جاف، مانع للانفجار**، مناسبة للوسائط الخطرة. الكهربائية تستخدم محركًا، لا تحتاج مصدر هواء لكن خطر الشرر. غونهاي توزع **مضخات غشائية هوائية ARO** للكيمياء/الأدوية/الأغذية/الإلكترونيات.
</details>

<details dir="rtl">
<summary><b>س3: تروس داخلية أم طاردة مركزية؟</b></summary>

التروس الداخلية هي مضخة إزاحة موجبة، مناسبة **للوسائط عالية اللزوجة** (1~500,000 ملPa·s)، تدفق صغير، ضغط عالٍ. الطاردة المركزية هي مضخة سرعة، مناسبة **لتدفق كبير لزوجة منخفضة**. DAIDO توزع مضخات تروس للكيمياء/الراتنج/الزيوت - تطبيقات اللزوجة العالية.
</details>
