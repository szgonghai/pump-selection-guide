## 🧪 Selection Decision (4 Steps)

### Step 1 · Media Type (Determines Pump Type)
```
                ┌─ Solids / high viscosity / abrasive ──→ Diaphragm Pump (ARO)
                │
Media ─┤ Strong acid / base / flammable ──→ Magnetic Pump (PTCXPUMP/INNOMAG)
                │
                ├─ Precise dosing / quantitative ──→ Metering Pump
                │
                └─ Clean water / low viscosity / circulation ──→ Centrifugal Pump (PTCXPUMP)
```

### Step 2 · Key Parameters
| Parameter | Consideration |
|-----------|---------------|
| **Flow** | Process demand (normal + peak) |
| **Head** | System resistance + static head + safety margin |
| **Temperature** | Affects material choice (PTFE / ETFE / SS) |
| **Pressure** | Working pressure vs pump rated pressure |
| **Viscosity** | High viscosity requires more power |
| **Solid content** | Particles → diaphragm or screw pump required |

### Step 3 · Special Requirements
| Requirement | Selection |
|-------------|-----------|
| **Zero leakage** (hazardous/corrosive) | Magnetic Pump |
| **Dry-run capable** (anti-cavitation) | Diaphragm Pump |
| **High purity** (semiconductor/food) | Magnetic Pump (316L polished) |
| **High pressure** (> 10 bar) | Magnetic Pump / Centrifugal Pump |
| **Explosion-proof** (flammable gas) | Magnetic Pump (no motor) / ARO (pneumatic) |
| **Strong acid resistant** | Magnetic Pump (PTCXPUMP engineering plastic / INNOMAG ETFE) |

## ❓ FAQ

<details>
<summary><b>Q1: Magnetic vs Centrifugal Pump?</b></summary>

**Magnetic Pump**: Static seal, zero leakage, suitable for strong acid/base/flammable/high purity media. **Centrifugal Pump**: High efficiency, versatile, large flow, but mechanical seal leakage risk, not for high viscosity. Standard industry → centrifugal; hazardous/corrosive media → magnetic.
</details>

<details>
<summary><b>Q2: Pneumatic vs Electric Diaphragm Pump?</b></summary>

Pneumatic (ARO) uses compressed air, **dry-run capable, explosion-proof**, suitable for hazardous media. Electric uses motor, no air source needed but has spark risk. Gonghai distributes **ARO pneumatic diaphragm pumps** for chemical/pharmaceutical/food/electronics.
</details>

<details>
<summary><b>Q3: Internal Gear vs Centrifugal Pump?</b></summary>

Internal gear is positive displacement, suitable for **high viscosity fluids** (1~500,000 mPa·s), but small flow and high pressure. Centrifugal is velocity type, suitable for **large flow low viscosity**. DAIDO distributed gear pumps cover chemical/resin/oil high viscosity applications.
</details>
