# 工業泵浦選型指南

> **如何為你的工況選擇正確的泵浦**  
> 基於 40 年行業經驗，覆蓋磁力泵、離心泵、隔膜泵、計量泵的選型決策樹

## 選型決策流程圖

```
開始
  ↓
[問題 1] 介質是否有毒/易燃/強腐蝕？
  ↓ YES                ↓ NO
磁力泵類          [問題 2] 需要精確定量添加嗎？
                    ↓ YES              ↓ NO
                計量泵          [問題 3] 含固體顆粒或高粘度？
                                    ↓ YES              ↓ NO
                                隔膜泵          離心泵
```

## 決策快速對照表

| 工況特徵 | 推薦泵型 | 主要原因 |
|---------|---------|---------|
| 強腐蝕、易燃易爆 | 磁力泵 | 靜密封，無洩漏 |
| 精確計量添加 | 計量泵 | 流量精度高 |
| 含顆粒、高粘度 | 隔膜泵 | 通過性強，不易堵塞 |
| 中低粘度、淨水 | 離心泵 | 通用性強，效率高 |

## 關鍵參數

- 介質特性（濃度、溫度、密度、粘度）
- 流量需求（最大流量、常用流量）
- 揚程需求（實際揚程、阻力損失）
- 材質選擇（金屬/非金屬）
- 溫度範圍
- 潔淨度要求
