## 🧪 选型决策（4 步走）

### Step 1 · 介质类型（决定泵型）

```
                ┌─ 含颗粒/高粘/磨蚀 ──→ 气动隔膜泵 (ARO)
                │
介质 ─┤ 强酸/强碱/易燃 ──→ 磁力泵 (PTCXPUMP/INNOMAG)
                │
                ├─ 精确加药/定量 ──→ 计量泵
                │
                └─ 清水/低粘/循环 ──→ 离心泵 (PTCXPUMP)
```

### Step 2 · 关键参数
| 参数 | 关注点 |
|------|------|
| **流量** | 工艺需求流量（含峰值）|
| **扬程** | 系统阻力 + 静扬程 + 安全余量 |
| **温度** | 影响材质选择（PTFE / ETFE / 不锈钢）|
| **压力** | 工作压力 vs 泵的额定压力 |
| **黏度** | 高粘度需要更大功率 |
| **固体含量** | 含固 → 必须选隔膜泵或螺旋泵 |

### Step 3 · 特殊要求
| 要求 | 选型 |
|------|------|
| **零泄漏**（危险/腐蚀介质）| 磁力泵 |
| **可干转**（防气蚀）| 隔膜泵 |
| **高洁净**（半导体/食品）| 磁力泵（316L 抛光）|
| **高压**（> 10 bar）| 磁力泵 / 离心泵 |
| **防爆**（易燃气体）| 磁力泵（无电机）/ ARO（气动）|
| **耐强酸** | 磁力泵（PTCXPUMP 工程塑料 / INNOMAG ETFE）|

## ❓ 常见问题

<details>
<summary><b>Q1：磁力泵和离心泵怎么选？</b></summary>

**磁力泵**：无泄漏（静密封），适合强酸/强碱/易燃/高纯介质，但不适合含固颗粒。**离心泵**：高效、通用、大流量，但有机封泄漏风险，不适合高粘度。普通工业选离心泵，危险/腐蚀介质选磁力泵。
</details>

<details>
<summary><b>Q2：气动隔膜泵和电动隔膜泵的区别？</b></summary>

气动（ARO）以压缩空气为动力，**可干转、防爆、适合危险品**；电动以电机驱动，无需气源但有电火花风险。**弓海主推 ARO 气动隔膜泵**，覆盖化工/制药/食品/电子等。
</details>

<details>
<summary><b>Q3：内转齿轮泵和离心泵的区别？</b></summary>

内转齿轮泵是容积式泵，适合**高粘度流体**（1~500,000 mPa·s），但流量小、压力高；离心泵是速度式泵，适合**大流量低粘度**。DAIDO 代理的齿轮泵覆盖化工/树脂/油脂等高粘度应用。
</details>
