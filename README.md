# 工业泵浦选型指南

> **如何为你的工况选择正确的泵浦**  
> 基于 40 年行业经验，覆盖磁力泵、离心泵、隔膜泵、计量泵的选型决策树

## 选型决策流程图

### 完整决策树

```
开始
  ↓
[问题 1] 介质是否有毒/易燃/强腐蚀？
  ↓ YES                ↓ NO
磁力泵类          [问题 2] 需要精确定量添加吗？
                    ↓ YES              ↓ NO
                计量泵          [问题 3] 含固体颗粒或高粘度？
                                    ↓ YES              ↓ NO
                                隔膜泵          离心泵
```

### 决策快速对照表

| 工况特征 | 推荐泵型 | 主要原因 |
|---------|---------|---------|
| 强腐蚀、易燃易爆 | 磁力泵 | 静密封，无泄漏 |
| 精确计量添加 | 计量泵 | 流量精度高 |
| 含颗粒、高粘度 | 隔膜泵 | 通过性强，不易堵塞 |
| 中低粘度、净水 | 离心泵 | 通用性强，效率高 |

## 1. 磁力泵选型

### 适用场景

- 强腐蚀性化学介质（酸、碱、盐溶液）
- 易燃易爆介质（醇类、酮类、有机溶剂）
- 高纯度要求（半导体、食品、医药）
- 不允许泄漏的关键工艺

### 关键参数

- **介质特性**：浓度、温度、密度、粘度
- **流量需求**：最大流量、常用流量
- **扬程需求**：实际扬程、阻力损失
- **材质选择**：金属（不锈钢/合金）或非金属（PP/PVDF/ETFE）
- **温度范围**：操作温度、最高温度
- **洁净度要求**：SEMI 标准、医药级标准

### 推荐产品

- **PTCXPUMP PS/PL 系列**：金属不锈钢，标准化工况
- **INNOMAG U-MAG/TB-MAG**：内衬系列，强腐蚀/高纯度

---

## 2. 计量泵选型

### 适用场景

- 精确添加化学品（絮凝剂、消毒剂、pH调节剂）
- 工艺配方比例投加
- 定量灌装、批次投料

### 关键参数

- **流量精度**：±1% 或 ±0.5%
- **投加压力**：背压要求
- **介质粘度**：影响泵型选择
- **脉动性**：单缸/双缸/多缸

### 推荐产品

- **顺益（SHUN-YI）计量泵系列**

---

## 3. 隔膜泵选型

### 适用场景

- 含固体颗粒或纤维的介质
- 高粘度介质（浆料、胶体）
- 易燃易爆、强腐蚀
- 重工况矿山、陶瓷、油田

### 关键参数

- **颗粒大小**：避免超过进/出口口径
- **干运转能力**：气动隔膜泵可干运转
- **压缩空气压力**：气动型需要气源
- **材质选择**：丁腈橡胶、氟橡胶、PVDF、铝合金

### 推荐产品

- **ARO 气动隔膜泵系列**

---

## 4. 离心泵选型

### 适用场景

- 清水、循环水、冷却水
- 低粘度液体（< 100 cP）
- 大流量、低扬程
- 标准工业流程

### 关键参数

- **流量（Q）**：m³/h 或 L/min
- **扬程（H）**：m 或 bar
- **吸入条件**：NPSHa > NPSHr
- **转速**：2 极/4 极/6 极
- **密封形式**：机械密封 / 磁力驱动

### 叶轮类型

- **闭式叶轮**：效率高，适用清水
- **半开式叶轮**：中等颗粒工况
- **开式叶轮**：高粘度、含纤维

## 选型步骤

### 步骤 1：收集工况参数

```
- 介质名称、化学成分
- 介质浓度、密度、粘度
- 操作温度（最低/最高）
- 流量需求（正常/最大）
- 扬程需求（实际计算）
- 吸入条件（NPSH available）
- 现场环境（温度、湿度、防爆要求）
```

### 步骤 2：确定泵型大类

```
介质有毒/易燃/强腐蚀 → 磁力泵
精确计量添加 → 计量泵
含固体/高粘度 → 隔膜泵
低粘度清水 → 离心泵
```

### 步骤 3：选择产品系列

根据具体参数：
- 流量范围
- 扬程需求
- 材质要求
- 温度范围
- 洁净度要求

### 步骤 4：确认细节

- 接口标准（ANSI/JIS/DIN/GB）
- 电机规格（功率、电压、防护等级）
- 辅助配置（阀门、仪表、管道）

## 选型误区

### 误区 1：只看价格

价格不是唯一因素。考虑：
- 全生命周期成本
- 维护成本
- 故障停机损失

### 误区 2：选型过大

过大的泵：
- 能量浪费
- 汽蚀风险
- 投资成本高

### 误区 3：忽视介质特性

- 浓度超过材质耐受范围
- 温度超过设计极限
- 颗粒堵塞流道
