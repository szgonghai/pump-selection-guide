# 泵浦选型详细指南

## 1. 选型流程（详细版）

### 阶段 1：工况调研

**必填参数**：
- 介质名称
- 介质浓度
- 操作温度（最低/最高）
- 流量需求（正常/最大）
- 扬程需求
- 入口压力条件
- 现场环境

**选填参数**：
- 介质粘度
- 介质密度
- 固体含量
- 蒸汽压
- 工艺要求（洁净度、防爆等）

### 阶段 2：泵型选择

根据工况调研结果，确定泵型：

| 工况特征 | 推荐泵型 |
|---------|---------|
| 强酸强碱 / 易燃易爆 / 高纯度 | 磁力泵 |
| 精确投加 / 计量添加 | 计量泵 |
| 固体颗粒 / 高粘度 / 浆料 | 隔膜泵 |
| 清水 / 循环水 / 标准化工况 | 离心泵 |

### 阶段 3：规格计算

**流量计算**：
```
Q(实际) = Q(正常) × 安全系数
其中安全系数 = 1.05-1.20
```

**扬程计算**：
```
H(总) = H(实际) + H(管损) + H(阀损) + H(余量)
其中 H(余量) = 总扬程 × 10-20%
```

**轴功率计算**：
```
P = (ρ × g × Q × H) / (1000 × η)
其中 η 为泵浦效率，通常 0.5-0.85
```

**电机功率**：
```
P(电机) = P(轴) × 1.15-1.30
```

### 阶段 4：材质选择

| 介质 | 推荐材质 |
|------|---------|
| 清水 | 铸铁、304 不锈钢 |
| 一般酸碱 | 316L 不锈钢、PP、PVDF |
| 强酸 | 哈氏合金、ETFE 内衬 |
| 强碱 | 镍合金、ETFE 内衬 |
| 有机溶剂 | 316L、双相钢 |

### 阶段 5：详细规格确认

- 接口标准（ANSI/JIS/DIN/GB）
- 电机规格（功率、电压、防护等级）
- 密封形式（机械密封 / 磁力驱动）
- 辅助配件（阀门、仪表、管道）

## 2. 选型计算示例

### 示例：化工废液输送

**工况**：
- 介质：20% NaOH 溶液
- 温度：60°C
- 流量：30 m³/h
- 扬程：20 m
- 入口条件：常压

**步骤 1：泵型选择**
- 强腐蚀性 → 磁力泵

**步骤 2：流量计算**
- Q(实际) = 30 × 1.1 = 33 m³/h

**步骤 3：扬程计算**
- H(实际) = 20 m
- H(管损) = 5 m（估算）
- H(阀损) = 2 m
- H(余量) = 27 × 0.15 = 4 m
- H(总) = 20 + 5 + 2 + 4 = 31 m

**步骤 4：选择型号**
- PTCXPUMP PS 系列
- 流量 33 m³/h，扬程 31 m
- 材质：316L 不锈钢
- 电机：5.5 kW

## 3. 选型常见疑问

### Q1：泵浦的轴功率小于电机功率？

是的。泵浦效率（0.5-0.85）需要考虑，所以电机功率要选大于轴功率的型号。

### Q2：泵浦的扬程随流量变化？

是的。流量越大，扬程越低。这是泵浦的特性曲线。

### Q3：是否所有磁力泵都能干运转？

**不能**。磁力泵的隔离罩在干运转时会因摩擦升温过快而损坏。

### Q4：气动隔膜泵和电动隔膜泵哪个好？

- **气动**：可干运转，更安全，但需要气源
- **电动**：节能，但密封要求高
